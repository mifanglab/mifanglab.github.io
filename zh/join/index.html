# 加入 MI² Lab

研究生培养 · 科研训练 · 医工合作

面向临床真实问题，构建医学智能

我们欢迎希望把严谨计算方法与真实医学问题结合起来的同学。课题组兼顾基础算法、多模态医学数据和医院临床合作，推动研究成果走向可验证的医学价值。

查看申请流程

# 为什么选择 MI² Lab

问题驱动的研究实践

从具体医学问题出发，逐步完成问题定义、方法设计、实验验证和论文表达，建立完整的科研工作方法。

高水平科研训练

研究成果发表于 TPAMI、TMI、Medical Image Analysis、JBHI、Pattern Recognition、MICCAI 等重要期刊与会议。

紧密临床连接

围绕医学影像和临床数据开展合作，将算法转化为可量化的影像标志物和诊疗支持工具。

# 希望你是

  • 计划申请南京大学硕士、普通博士或直博项目。
  • 具有计算机、生物医学工程、医学影像、临床医学、应用数学或相关专业背景。
  • 对医学影像、计算机视觉、多模态大模型、医学智能体或医工交叉研究有明确兴趣。
  • 具备良好的编程与数学基础；有论文成果或开源项目经验者优先。
  • 做事踏实、重视合作，遇到问题主动沟通，愿意长期投入科研。

同样欢迎

科研助理、实习生、访问学生，以及来自医院、影像中心和生命科学团队的合作者。

# 招生信息

所在单位南京大学（苏州校区）生物医学工程学院
招生导师张炯老师
招生类型硕士 · 普通博士 · 直博

# 申请流程

1

判断方向匹配

阅读课题组近期论文和项目成果，明确自己感兴趣的具体医学问题或技术方向。

2

准备申请材料

准备简短自我介绍、个人简历、成绩单和研究兴趣；如有论文、代码或项目，请附相关链接。

3

联系课题组

发送邮件至 lixiang.cog@smail.nju.edu.cn。正式申请按南京大学及学院最新通知执行。

开始交流

告诉我们，你希望解决什么医学问题。

具体名额和时间安排以学校当年度招生计划为准。
