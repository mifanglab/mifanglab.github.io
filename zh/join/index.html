# 加入 MI² Lab

硕士 · 博士 · 科研助理 · 实习生

面向真实医学问题开展研究

课题组长期欢迎对医学影像、计算机视觉和医工交叉感兴趣的学生与研究人员。研究从具体问题出发，重视方法设计、实验验证和临床合作。

查看申请方式

# 科研环境与培养

研究训练

围绕明确问题完成文献调研、方法设计、实验分析和论文写作，形成完整的科研训练闭环。

临床合作

结合医学影像和临床数据，与医院及合作团队共同讨论问题、验证方法并分析结果。

交流与发表

鼓励开放讨论、代码实践和学术交流，支持在医学影像与人工智能领域的重要期刊和会议发表成果。

# 希望你是

  • 计划申请南京大学硕士、普通博士或直博项目。
  • 具有计算机、生物医学工程、医学影像、临床医学、应用数学或相关专业背景。
  • 对医学影像、计算机视觉、多模态大模型、医学智能体或医工交叉研究有明确兴趣。
  • 具备良好的编程与数学基础；有论文成果或开源项目经验者优先。
  • 做事踏实、重视合作，遇到问题主动沟通，愿意长期投入科研。

其他合作方式

也欢迎科研助理、实习生、访问学生，以及来自医院、影像中心和生命科学团队的合作者联系交流。

# 申请流程

1

了解课题组

阅读近期论文和项目成果，确认自己感兴趣的医学问题或技术方向。

2

准备材料

准备简短自我介绍、个人简历、成绩单和研究兴趣；如有论文、代码或项目，请附相关链接。
